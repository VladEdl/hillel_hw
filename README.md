# HILLEL_HW
## “Read more” через data- + делегацію*
### Мета: відпрацювати dataset, closest, делегацію, classList.
#### Вимоги:
1. На сторінці є 3–5 карток тексту
2. Кожна має короткий (видимий) і довгий (прихований) текст
3. Кнопка з data-read-more-btn
4. Клік:
   5. показує/ховає довгий текст
   6. змінює текст кнопки “Read more” ⇄ “Hide”
   7. додає/прибирає клас expanded
8. Єдиний обробник — на контейнері

#### Критерії:
1. Працює для будь-якої кількості карток
2. closest() використано
3. Без innerHTML
